# 스페이싱 반응 (SPACING_RESPONSE) 설계 (2026-11-11, 측정 완료 · 강도/기준/순서 결정 대기)

> 이름 확정(11-11): 로직 = **스페이싱 반응**(`SPACING_RESPONSE`). 하위 이름 — 스페이싱 지수 `spacingIndex`(S) / 스페이싱 편차 `spacingDev`(dev) / 시대 기준 스페이싱 `REF_BY_ERA` / 헬프 빈도 반응 `HELP_MULT` / 프로텍터 체류 `PROTECTOR_SHIFT` / 세깅 `SAG`. "그래비티"는 스코어링 그래비티(볼 핸들러 쪽)와 충돌해 쓰지 않음.

## 배경
- 엔진에서는 림 비중을 22% → 35%로 올려도 림 1개당 득점이 떨어지지 않는다(11-07 측정). 실제는 림 비중이 높은 팀일수록 림 성공률이 낮다(60팀-시즌 단면, 비중 1%p당 −0.34%p, 상관 −0.34 — 로스터 차이가 섞인 추정치).
- 같은 로스터로 공격 슛 슬라이더만 바꾼 교차 실험에서 인사이드 극단 전술이 100포세션당 +1.5 유리했고(2020년대 프리셋·재수출 로스터 기준), 우위는 전부 자유투에서 나온다. 인사이드 극단에 대가가 없어 유저 일부가 그쪽으로 몰린다(3PA 13~16개 팀).
- 근본 원인(사용자 합의, 11-11): **좋은 슛은 수비가 비운 자리에서만 나오고, 수비는 위협이 있는 곳에만 자리를 비운다.** 공격 효율은 수비 위치의 함수이고 수비 위치는 공격의 위협 분포의 함수인데, 엔진의 수비는 경기 전 고정 슬라이더라 공격이 어디를 위협하든 같은 자리에 서 있다. 성공률 함수(`calculateHitRate`) 입력에 슛 횟수·팀 비중·코트 위 슈터 수가 전혀 없다.
- 엔진에서 수비 자원이 제로섬으로 작동하는 유일한 장치는 헬프↔킥아웃이다. "헬프를 가면 그 자리의 선수가 열린다"까지는 있고, **"열리는 선수가 약하면 헬프를 더 간다"**가 없다. 이 빠진 절반을 채우는 설계다.

## 설계
### 위협(스페이싱) 값 S — 포세션마다 계산
오프볼 공격 4명(액터 제외)의 외곽 위협 평균.
```
threat_j = cap3_j × p3_j
cap3_j   = clamp((threeVal_j − 50) / 35, 0, 1)                 // 3점 능력 계수 (85+ = 1, 50 이하 = 0)
p3_j     = s3 / (s3 + sMid + sIn)                              // 현재 공격 슬라이더에서 오픈 시 3점을 택할 확률 — selectZone과 같은 산식
           s3  = pref3 × (1 + (shot_3pt − 5)/5 × 0.5)          // pref3 < 0.15면 ×0.2 (selectZone 규칙 그대로)
           sMid = zonePref.mid × (1 + (shot_mid − 5)/5 × 0.5)
           sIn  = (zonePref.itp + zonePref.ra) × (1 + (shot_rim − 5)/5 × 0.5)
S        = mean_j threat_j
dev      = clamp((S_ref − S) / S_ref, −1, 1)                   // +면 스페이싱 부족, −면 과잉. 지역방어·속공 포세션은 0
```
- 능력 × 의지의 곱이다. 능력만 보면 로스터 기준 보정이 되어 전술 책임 원칙과 부딪히고, 의지만 보면 빅맨 5명과 슈터 4명을 세운 포스트업 팀이 같아진다.
- 선수 성향(`zonePref`, 실제 데이터)은 읽기만 한다. 공격 플레이 빈도는 건드리지 않는다 — 수비가 반응하는 것이다.

### 연동 지점 3곳 (가장 가벼운 조합, 전부 맨투맨 하프코트 한정)
| 지점 | 변경 | 계수 |
|---|---|---|
| 헬프 시도 확률 (`HELP_DEFENSE.ATTEMPT_*`) | `× clamp(1 + K·dev, 0.5, 2.0)`, 상한 0.95 | K = 1.0 |
| 림 프로텍터 개입 확률 (`resolveRimProtector`) | `engage += K2·dev` | K2 = 0.25 |
| 림·페인트 성공률 (`calculateHitRate` bonusHitRate 합산) | `− clamp(SAG·dev, ±0.05)` (킥아웃 슛 제외) | SAG = 0.04 (H2) 또는 0.08 (H3) |

- 3점에는 아무것도 걸지 않는다. 실제도 3점은 비중과 성공률이 무관하고, 3점 몰빵의 대가(자유투 감소)는 이미 들어가 있다.
- 지역방어 포세션은 dev = 0 — 지역방어의 내곽 억제(`INTERIOR_COEFF`)·3점 오픈과 이중 부과를 피한다.
- `S_ref`: 2020년대 0.365(NBA Active 중립 슬라이더 0.366·유저 전술 0.363 측정), 1990년대 0.26(PBL 유저 전술 0.257·Test 중립 0.263). 2010년대·2000년대는 측정 리그가 없어 보간(0.33·0.29, 추정).

## 결정 필요
1. 강도: H2(같은 로스터에서 인사이드 극단이 중립이 됨) / H3(스페이싱이 소폭 유리, 실제 방향에 더 가까움). 실제의 음의 기울기(−0.34)까지 가려면 세깅 0.15 안팎이 필요하나, 그 실제 수치는 로스터 차이가 섞인 추정치다.
2. 기준: 시대별 S_ref(권장 — 레전드 리그 중립 유지) / 2020년대 절대 기준(레전드 −0.5점).
3. 림 프로텍터 연동(K2) 포함 여부 — 포함 기준으로 측정됨. 제외하면 효과가 줄어 재측정 필요.
