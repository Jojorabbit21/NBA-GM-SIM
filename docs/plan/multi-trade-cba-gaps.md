## 구현 완료 (참고)

- 페이롤 구간별 매칭 — 캡 이하(잔여 캡 스페이스) / 캡~1차 에이프런(송신액 3단계: ≤$7.5M → ×2+$250K,
  $7.5M~$29M → +$7.5M, >$29M → ×1.25+$250K) / 1차 에이프런(100%) / 2차 에이프런(100% + 합산 금지)
- 페이롤 계산: 투웨이 제외, 데드머니 포함 (`team_current_payroll` SQL ↔ `calcTeamPayroll()` 미러)
- 서버 강제(`respond_trade_offer` accept 시 `salary_match_failed`) + 클라 사전 경고(양 팀) + "트레이드 조건" 상시 안내
- 리그 설정 토글 `trade_salary_matching_enabled`(cap_enabled와 AND 게이트), 트레이드 데드라인, 트레이드 블록 opt-in
